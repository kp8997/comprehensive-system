Take advantage of dynamic type of ruby:

  1. Keep name simple:
    name of everything will tell the type and purpose it serve. Keep it concise and meaningful

  2. No need type checking,
    No need to check instance of type then do something or raise error base on type
    
  3. No need base stuff
    No base class, no need interface, just define method and let it say about itself. Focus on what we need to write

  4. Comments and Test suite
  Take comments when methods are complex. Adding test is mandatory and high recommendation.
